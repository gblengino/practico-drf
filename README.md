# Trabajo Práctico Django DRF
## Proyecto: API para App para gestión de cantinas

El objetivo del proyecto es crear una API que conecte con una base de datos para una futura aplicación web para gestionar cantinas para **eventos de recaudación**.

#### Endpoints agregados

`` /api/products `` GET (all) y POST
`` /api/products/<int> `` GET (id), PUT y DELETE
